# Statement of Work: Praxis Implementation

## Executive Summary

[CLIENT] engages [VENDOR] to implement a Praxis-powered expert system for [DOMAIN]. This system will transform [CLIENT]'s documentation and institutional knowledge into an AI-powered assistant that learns and improves with use.

**Outcome:** A deployed expert system that answers [DOMAIN] questions with expert-level accuracy, learns from corrections, and captures institutional knowledge.

---

## Scope of Work

### Phase 1: Discovery & Assessment (Week 1-2)
| Deliverable | Description |
|-------------|-------------|
| Documentation Audit | Inventory of source materials (regulations, guides, internal docs) |
| Expert Interviews | Capture institutional knowledge from 2-3 subject matter experts |
| Gap Analysis | Identify what's documented vs. what experts "just know" |
| Architecture Plan | Technical design, hosting requirements, integration points |

**Exit Criteria:** Signed-off architecture document and prioritized knowledge map.

---

### Phase 2: Foundation Build (Week 3-4)
| Deliverable | Description |
|-------------|-------------|
| Data Ingestion Pipeline | Structured processing of source documents |
| Vector Database | Embedded and indexed knowledge base |
| Base RAG System | Query → Retrieval → Response working |
| Initial Testing | Baseline accuracy measurement |

**Exit Criteria:** System answers basic questions from documentation with citations.

---

### Phase 3: Institutional Knowledge Layer (Week 5-7)
| Deliverable | Description |
|-------------|-------------|
| Expert Translation Mapping | Convert SME knowledge into structured guidance |
| Practical Shortcuts | "What actually works" mappings |
| Edge Case Library | Common exceptions and how to handle them |
| API/Tool Integration | Connect to relevant systems (if applicable) |

**Exit Criteria:** System provides practical, actionable answers — not just doc quotes.

---

### Phase 4: Deployment & Training (Week 8)
| Deliverable | Description |
|-------------|-------------|
| Production Deployment | Hosted instance or on-prem installation |
| Expert Training | Train 2-3 users on refinement workflow |
| Refinement Process | Documented process for ongoing improvement |
| Handoff | Admin access, documentation, support contacts |

**Exit Criteria:** System live, experts trained, refinement loop active.
